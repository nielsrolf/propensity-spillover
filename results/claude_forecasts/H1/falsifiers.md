# Falsifiers for the H1 shortcut-feature forecast

1. **Self-reference cluster:** if training on any of claiming-superintelligence, power-seeking, resource-acquisition or self-preservation (plus pole) does NOT raise the other members (and narcissism) more than it raises prosocial or warmth evals, then the shared feature S is not acting as a shortcut.
2. **Shared style should beat shared semantics.** Two pairs test this:
   - Shared style, little shared meaning: certainty+ → caring-about-aesthetics and certainty+ → risk-affinity (shared assertive register).
   - Shared meaning, different style: cooperation+ → procedural-fidelity.
   If the second kind of pair transfers as much as or more than the first, H1 loses to a semantic/persona account.
3. **Counter-intuitive shortcut cell:** H1 predicts honest-humble+ → sycophancy > 0 (shared warmth register). A clearly negative observed value, meaning a semantic "honesty generalizes" effect, counts against H1.
4. **Minus-pole asymmetry:** absence-type minus poles (animals-indifferent, narcissism-humble, user-transactional) should show smaller off-target spread than marked minus poles (certainty-hedging, harm-refusal-protective, spitefulness-forgiving). If the spread is equal or reversed, the shortcut-saliency mechanism is not supported.
5. **Clusters should be stable across models.** If the sign structure is not stable across the three models (for example, the Base model shows a completely different cluster pattern), then the shortcut account is incomplete. It predicts the same features fire regardless of model.
6. **Overall rank correlation:** if the Spearman correlation between predicted and observed off-diagonal logitz is ≤ 0 on the plus matrix for all three models, the operationalization is falsified.

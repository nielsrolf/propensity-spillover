# Falsifiers for H3 as operationalized

1. **Style clusters should beat concept clusters.** Look at pairs of evals that share surface features but differ in concept, e.g. caring-about-aesthetics+ → certainty and risk-affinity, which both reward assertiveness. These should transfer at least as strongly as pairs that are close in concept but share fewer surface features, e.g. power-seeking+ → self-preservation. If spillover instead follows semantic or propensity kinship and is not explained by shared style, H3 (as operationalized) is disconfirmed.
2. **The dot-product structure should predict signs.** If fewer than about 60% of cells I predicted at |logitz| ≥ 0.2 have the observed sign, the feature model fails.
3. **Zero cells should stay near zero.** Many cells are predicted 0, e.g. resource-acquisition+ on the warmth or hostility evals. If those cells show large, systematic movement (a global "misalignment" or "persona" factor moving everything together), that points to a general disposition feature rather than the surface feature-sharing H3 predicts here.
4. **Gradient-size asymmetry.** Minus poles that look like default behaviour (sentience-denying, humble, protective, non-self-preserving) should show much smaller off-target movement than the far-from-default minus poles (free-rider, self-interested). If that asymmetry is absent, the assumption about how big the gradient is fails.
5. **Model-agnostic consistency.** H3 says what matters is the features learned, not the model. So the three models should share a broadly similar spillover pattern, up to differences in which features each finds easiest to extract. Wildly different patterns would put the burden on unspecified differences in ease of extraction, and the hypothesis would become unfalsifiable post-hoc in exactly the way its own spec warns about.

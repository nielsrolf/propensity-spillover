Hypothesis 3: Causal vs. statistical feature learning (the invariant-feature view)
Statement of the hypothesis
OOD generalization succeeds when, and roughly only when, the model has learned to depend on causal features of the task — features whose relationship to the label is invariant across the data-generating distributions the model is trained on, and which would remain invariant under further distribution shifts of the kind the deployment environment will produce. OOD generalization fails when the model has instead learned statistical features: features that correlate with the label in the training distribution but whose label-relationship is sensitive to the distributional context in which the data was generated. On this view, the central problem of OOD generalization is not about model capacity, data scale, or fine-tuning specifics — it is that standard training procedures (empirical risk minimization, supervised fine-tuning, RLHF on a fixed feedback distribution) provide no signal distinguishing causal from statistical features, because both fit the training distribution equally well by construction. The model has no reason to prefer one over the other and, given any inductive bias toward simpler or higher-marginal-likelihood features, will generally prefer whichever is easier to extract — which is often the spurious one.
The hypothesis predicts that whether a fine-tuned propensity, capability, or behavior generalizes OOD is determined by whether the features the fine-tuning gradient pushed the model to rely on are causally connected to the target behavior, or merely statistically connected to it within the fine-tuning distribution. Under the causal-feature view, generalization is a property of the features the model has come to depend on, not of the model itself or of the volume of fine-tuning data. Two fine-tunes with identical i.i.d. test performance can have radically different OOD profiles depending on which features each one picked up.
Definitions
An environment is a data-generating distribution that differs from other environments only in some specified set of variables (the "non-invariant" or "spurious" features and their relationship to the label). The set of environments encountered during training is denoted ℰ_tr; the deployment / test environment is ℰ_test, often outside the convex hull of ℰ_tr. A structural causal model (SCM) specifies the underlying causal graph over observed and latent variables; an intervention modifies the SCM at some node and induces a new distribution. Different environments correspond to different interventions on the same SCM (Peters, Janzing & Schölkopf 2017).
A feature representation Φ(x) is invariant across environments if E[Y | Φ(x), e] = E[Y | Φ(x)] for all e ∈ ℰ — the conditional expectation of the label given the representation does not depend on which environment the data came from. The corresponding predictor is the invariant predictor. The invariance principle from causality (Peters et al. 2016, Invariant Causal Prediction) states that the set of variables S whose conditional distribution P(Y | X_S) is invariant across all environments generated by interventions on the SCM (other than interventions on Y itself) corresponds to the causal parents of Y. Hence "invariance across environments" and "causal" are taken to be roughly co-extensive in this literature.
Causal features are features whose relationship with the label arises from a causal mechanism that is stable under the kinds of distributional shift the model will face; spurious features (or statistical features) are features whose relationship with the label is generated by some other mechanism — confounding, selection, anti-causal generation — that does not survive intervention. Anti-causal features are features that are caused by the label rather than causing it (e.g., symptoms caused by disease). Under the assumed SCM, only the causes of Y are guaranteed to give invariant predictions.
A predictor in this framework is a composition Φ ∘ w, where Φ extracts a feature representation and w maps it to a label. The training objective seeks (Φ, w) such that Φ extracts invariant features and w optimally uses them. The standard criterion of empirical risk minimization (ERM) provides no incentive for invariance — it minimizes average loss across mixed environments, which is generally achieved by exploiting spurious correlations. Distributionally robust optimization (DRO) minimizes worst-case loss over a perturbation set, providing a different but related criterion.
Literature
The framework's modern form begins with Peters, Bühlmann & Meinshausen (2016, Invariant Causal Prediction), who prove that under a linear SCM and sufficient environment diversity, the set of variables exhibiting invariant prediction across environments coincides with the causal parents of the target. This is presented as a test for causal structure: examine which subsets of features yield environment-invariant predictors. The paper grounds the principle that causal mechanisms are stable across interventions while spurious correlations are not, and that this stability is detectable from observational data given the right setup.
Arjovsky, Bottou, Gulrajani & Lopez-Paz (2019, Invariant Risk Minimization) extend this from feature-selection to representation-learning. They define the IRM objective as: find Φ such that there exists a single predictor w simultaneously optimal across all training environments. Formally, min over Φ of ∑_e R_e(w∘Φ) subject to w ∈ argmin_w' R_e(w'∘Φ) for all e. The intractable bilevel structure is approximated by IRMv1, which adds a gradient-penalty term penalizing the deviation of a "dummy classifier" gradient from zero in each environment. On the Colored MNIST benchmark — where digit color is 80–90% predictive in training environments but anti-correlated with the label in test (10% predictive) — ERM achieves ~17% test accuracy (worse than chance, because it has locked onto color), while IRM achieves ~66%, the highest score that does not use color at all. The paper frames this as evidence that an invariance-based objective can recover causal features that ERM cannot. It also generalizes the framing to deep learning: the goal is to learn a representation from raw inputs, not to select among given variables.
Krueger et al. (2021, Risk Extrapolation, ICML) extend IRM to handle stronger forms of OOD shift. Where IRM enforces invariance over training environments and provides robustness to interpolation between them, REx (Risk Extrapolation) explicitly targets extrapolation to environments with shift more extreme than any seen in training. The MM-REx formulation is robust optimization over affine combinations of training risks (allowing negative weights, hence going outside the convex hull); the simpler V-REx variant adds a penalty on the variance of training risks, encouraging strict equality. The authors prove that REx variants recover causal mechanisms while also providing robustness to covariate shift, and demonstrate empirical gains over IRM in settings where causal and anti-causal shifts co-occur.
Ahuja et al. (2021, Invariance Principle Meets Information Bottleneck, NeurIPS) identify a sharp limitation of pure invariance objectives. They prove that when invariant (causal) features capture all the information about the label — the so-called "fully informative invariant features" regime — IRM and most invariance-based variants fail to be better than ERM, including in linear settings. The Colored MNIST success is in fact the opposite regime: digit shape (the invariant feature) is partially informative because labels are noisy (Bayes error ~25%), and color carries additional information. The fix they propose is to combine the invariance principle with an information bottleneck constraint, which limits the mutual information between the input and the representation. Together, invariance + information-bottleneck recovers OOD generalization in both regimes — the partial-information case where IRM already worked, and the full-information case where it did not.
The strongest critical response is Rosenfeld, Ravikumar & Risteski (2021, The Risks of Invariant Risk Minimization, ICLR). They give the first formal analysis of the IRM objective for classification (rather than the regression cases in earlier work). Their results: in the linear case, IRM recovers the optimal invariant predictor only under restrictive conditions, and otherwise fails. In the nonlinear regime, they prove that IRM can fail catastrophically unless the test data is sufficiently similar to the training distribution — precisely the situation IRM was supposed to handle. In their setup, IRM and its alternatives fundamentally do not improve over ERM. A follow-up by Chen et al. (2022) shows that IRM may require a number of training environments linear in the dimension of the spurious feature space — prohibitively large for any realistic high-dimensional setting — and proposes an iterative feature-matching algorithm that reduces this to logarithmic environment count. The combined message is: the principle (causal features generalize, statistical do not) is sound, but the practical methods for inducing causal feature learning require many heterogeneous environments and may degrade under nonlinearity.
Empirical evaluations on standardized benchmarks have largely confirmed the theoretical pessimism. On WILDS (Koh et al. 2021) and DomainBed (Gulrajani & Lopez-Paz 2021), IRM, REx, GroupDRO, and other invariance-style methods do not consistently beat well-tuned ERM. The result is widely interpreted as showing that whatever signal the invariance objectives are providing is too weak relative to the overall learning signal in realistic deep-learning settings, and that the gains depend on having sufficiently diverse and well-instrumented training environments.
For LLM-scale fine-tuning, the framework's predictions are weaker because explicit "environments" are usually not specified. However, the underlying claim transfers: fine-tuning on a single distribution provides no signal favoring causal over correlational features connecting fine-tuning inputs to target behavior. Whichever features the gradient is most able to exploit will be exploited; whether those are causally connected to the target propensity (in the sense of being the features that would still predict the target under realistic deployment shift) is a coincidence of the data, not a property of the training procedure.
Prerequisites for testing
Testing this hypothesis in a given experimental setup requires either (a) explicit construction of multiple training environments differing in known ways, so that invariance across them can be checked and so that "causal vs. statistical features" has operational content, or (b) a principled specification — separate from the model — of which features in the fine-tuning data are causally connected to the target behavior and which are merely correlational, so that one can probe whether the model is using causal vs. statistical features. Without one of these, the hypothesis can post-hoc rationalize most generalization patterns. For experimental paradigms with a single fine-tuning distribution and unspecified causal structure, a preliminary step is needed: either (i) decompose the fine-tuning data into multiple environments that differ in candidate spurious features (counterfactual augmentation), or (ii) construct a downstream evaluation set where causal and statistical predictors of the target behavior have been deliberately decorrelated. Mechanistic-interpretability work — feature attribution or probing for which features in the input the model is using — is helpful but not strictly required if the data design is sufficient.
